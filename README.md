# CMS Advanced Sommelier: study notes

Personal study notes for the Court of Master Sommeliers Europe Advanced Sommelier examination,
organised by the 2026/27 syllabus sections.

- `data.js`: syllabus sections and study notes
- `app.js`, `style.css`, `index.html`: the site
- `images/`: images used in the notes; `images/uploads/` + `uploads.json`: images added from the site

The previous version of this repository is kept on the `old-site` branch.
